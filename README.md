# Vexely

**English** · [Português](#português)

**A free, open-source desktop board for AI coding agents.**

Run Claude Code, Codex, Gemini CLI and other agent CLIs in real terminals, side by side on one infinite canvas. See at a glance which agent is working, idle or waiting for you, and pick up where you left off.

> 🚧 **Early development.** Vexely is not ready to use yet. Follow the repo for updates.

### Planned features

- **Real terminals:** each node is a full terminal running the CLI you already use, with your own account and subscription.
- **Infinite board:** pan and zoom across as many agents as you need, with notes and a kanban next to them.
- **Agent status:** working, idle or waiting for input, shown on every terminal.
- **Resume:** close the app and reopen it with your board and agent sessions restored.
- **Local-first:** everything stays on your machine. No account, no server, no subscription.

### Platforms

Windows, Linux and macOS.

### Built with

[Electron](https://www.electronjs.org/) · [React](https://react.dev/) · [React Flow](https://reactflow.dev/) · [xterm.js](https://xtermjs.org/) · [node-pty](https://github.com/microsoft/node-pty)

## Português

[English](#vexely) · **Português**

**Um quadro desktop gratuito e de código aberto para agentes de IA de programação.**

Rode Claude Code, Codex, Gemini CLI e outros agentes em terminais reais, lado a lado num canvas infinito. Veja de relance qual agente está trabalhando, parado ou esperando você, e continue de onde parou.

> 🚧 **Em desenvolvimento inicial.** O Vexely ainda não está pronto para uso. Acompanhe o repositório para novidades.

### Funções planejadas

- **Terminais reais:** cada nó é um terminal completo rodando o CLI que você já usa, com a sua própria conta e assinatura.
- **Quadro infinito:** mova e dê zoom entre quantos agentes precisar, com notas e um kanban ao lado.
- **Status dos agentes:** trabalhando, parado ou esperando você, em cada terminal.
- **Retomar:** feche o app e reabra com o quadro e as sessões dos agentes restaurados.
- **Local:** tudo fica no seu computador. Sem conta, sem servidor, sem assinatura.
